# 長度積木基地

小三（香港）長度單位換算電子白板遊戲。三名學生在**同一部裝置、同一個畫面**合作：先討論，再按答案。答對就放下一塊積木，並逐步解鎖新的建造方向。

建造不限於向上。方向依次為：

1. 向上
2. 向前
3. 向左
4. 向右
5. 向下
6. 隧道

上一個方向建成 **2** 塊，就解鎖下一個方向。每個方向至少 **3** 塊（最多 4 塊）才算完工。六個方向都完工，秘密基地就建成。

畫面會輪流提示由 1 號、2 號、3 號按鍵，但**不會鎖住按鈕**。討論完，任何一位同學都可以按。

## 環境

- Node.js 18 或以上
- 現代瀏覽器（建議 Chrome 或 Edge）
- 裝置本身的繁體中文字型（例如微軟正黑體、蘋方）

## 在課室播放

```bash
npm install
npm run dev
```

終端機會顯示本機網址，通常是 `http://localhost:5173` 。用瀏覽器打開它。

同一網絡內的電子白板，可以打開終端機裡 **Network** 那一行網址。若打不開，請檢查電腦防火牆是否容許區域網絡連線。

## 電子白板全螢幕

1. 用白板電腦的瀏覽器打開遊戲。
2. 按右上角 **全螢幕**，或按鍵盤 `F11`。
3. 建議橫向 16:9，學生站在畫面正前方。
4. 三位同學先一起讀題、說出想法，再由今次提示的同學按下巨大答案按鈕。
5. 答錯會留下提示（例如 ×1000、÷1000），同一題可以再試。答錯的選項會標成「已試過」，方便小組記住。
6. 答對後，可以改按下方的方向按鈕，決定下一塊積木放在哪裡。

老師用手提電腦示範時，亦可用數字鍵 `1` 至 `4` 作答，用左右方向鍵切換已解鎖的方向。

## 建成靜態網頁

```bash
npm install
npm run build
npm run preview
```

`dist/` 就是整個網站，可以放到任何靜態網頁伺服器。預覽網址通常是 `http://localhost:4173` 。

## 題目

內置 64 題原創題目，每局隨機抽出，同一局不會重複，亦盡量不跟上一題相同。數字保持細小（幾公里加幾米、幾厘米加幾毫米、幾十毫米），重點是進率，不是多位數運算。題幹會夾雜中文單位（公里、米、厘米、毫米）和英文縮寫（km、m、cm、mm）。

| 題型 | 例子 |
| --- | --- |
| 公里 + 米 → 米 | 2 公里 3 米 = ______ 米 |
| 厘米 + 毫米 → 毫米 | 3 cm 4 mm = ______ mm |
| 毫米 → 厘米 + 毫米 | 35 mm = ______ |
| 米 → 公里 + 米 | 2003 米 = ______ |
| 米 + 厘米 → 厘米 | 1 米 4 厘米 = ______ 厘米 |
| 厘米 → 米 + 厘米 | 203 厘米 = ______ |
| 為日常物件選合適單位 | 硬幣的厚度、課室門的高度、校巴的長度等 |

重新整理頁面會清空進度。這版沒有帳戶、沒有連線對戰，也沒有成績表。
