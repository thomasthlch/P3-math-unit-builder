# 長度積木基地

小三（香港）長度單位換算電子白板遊戲。三名學生在**同一部裝置、同一個畫面**合作建造基地。上面是積木，下面分成三條一樣大的作答道，每人做自己的題。

## 合作規則

- 三條作答道各有一題，題目不相同，可以同時作答。
- **答對的人先選一件設備，再建到基地上。** 進度是共用的，上面看得到大門、塔樓、跑道等。
- 如果幾個人差不多同時答對，就按先答對的人先選，其他人排隊。
- 答錯會短暫顯示提示，然後換下一題，不會卡住其他人。
- 一開始可以建前兩件設備。每件要答對並放上 **5 次**才算完成（畫面只分「未起」「起緊」「完成」）。完成 1 件就再解鎖下一件。
- 每關約 **60 秒**。時間到不會失敗，會按已完成的設備給星星（最多 ★★★★★ 5 顆；六件裡完成 5 件即滿星）。基地仍留在畫面上。
- **第 1 關「秘密基地」**用長度換算。六件設備都建成後，會有完工畫面，再按 **下一關**。
- **第 2 關「時間車站」**用時間換算（小時、分、秒，進率 60），設備換成大鐘、月台、車頭等。建成後按 **再玩一次** 回到第 1 關。

## 環境

- Node.js 18 或以上
- 現代瀏覽器（建議 Chrome 或 Edge）
- 裝置本身的繁體中文字型（例如微軟正黑體、蘋方）

## 在課室播放

```bash
npm install
npm run dev
```

終端機會顯示本機網址，通常是 `http://localhost:5173` 。用瀏覽器打開它。

同一網絡內的電子白板，可以打開終端機裡 **Network** 那一行網址。若打不開，請檢查電腦防火牆是否容許區域網絡連線。

## 電子白板全螢幕

1. 用白板電腦的瀏覽器打開遊戲。
2. 按右上角 **全螢幕**，或按鍵盤 `F11`。
3. 建議橫向 16:9。三位同學各站一條作答道。
4. 按 **開始建造**。每人做自己格子裡的四選一。
5. 答對後，畫面上方會叫該同學選擇要建的設備。
6. 答錯不用重做同一題，看完提示就會換新題。
7. 第 1 關完成或時間到之後按 **下一關**。第 2 關完成或時間到之後按 **再玩一次**。

## 建成靜態網頁

```bash
npm install
npm run build
npm run preview
```

`dist/` 就是整個網站，可以用相對路徑放到 GitHub Pages 或其他靜態網頁伺服器。預覽網址通常是 `http://localhost:4173` 。

## 題目

第 1 關內置 64 題長度題，第 2 關另有 30 題時間題，都會隨機抽出。同一時間三條作答道不會用同一題。數字保持細小，重點是進率。題幹會夾雜中文單位和英文縮寫。

| 題型 | 例子 |
| --- | --- |
| 公里 + 米 → 米 | 2 公里 3 米 = ______ 米 |
| 厘米 + 毫米 → 毫米 | 3 cm 4 mm = ______ mm |
| 毫米 → 厘米 + 毫米 | 35 mm = ______ |
| 米 → 公里 + 米 | 2003 米 = ______ |
| 米 + 厘米 → 厘米 | 1 米 4 厘米 = ______ 厘米 |
| 厘米 → 米 + 厘米 | 203 厘米 = ______ |
| 為日常物件選合適單位 | 硬幣的厚度、課室門的高度、校巴的長度等 |

重新整理頁面會清空進度。這版沒有帳戶、沒有連線對戰，也沒有成績表。
